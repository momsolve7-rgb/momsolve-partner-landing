# 맘솔브 산후조리원 제휴 문의 페이지 — 개발 핸드오프

자사몰(momsolve.co.kr) 톤앤매너에 맞춰 제작한 **산후조리원 제휴 문의 랜딩페이지** 시안입니다.
레퍼런스 `ollocdam.com/partner.html`(약국 입점 제휴) 구조를 맘솔브 핑크/화이트로 재구성했습니다.

## 파일
- `index.html` — 단일 파일(HTML+CSS+최소 JS). 브라우저로 바로 열면 완성 화면 확인 가능.
- `preview_desktop.png` / `preview_mobile.png` — 전체 미리보기 이미지.

## 페이지 구성 (위 → 아래)
1. 헤더 (로고 · GNB · "산후조리원 제휴 문의" CTA, sticky)
2. 히어로 ("산모의 첫 케어, 맘솔브와 함께" + CTA 2개 + 비주얼)
3. WHY MOM SOLVE — 가치 3카드
4. LINEUP — 제품 3카드 (튼사렌/퓨어렌/베베솔브)
5. PARTNERSHIP BENEFIT — 제휴 혜택 (이미지 + 번호 리스트 3)
6. EASY TO START — 쉽게 시작 3카드 (간편 발주 / 최소 수량 / 전담 CS)
7. PROCESS — STEP 1·2·3
8. CONTACT — 제휴 문의 폼
9. 푸터 (회사정보)

## 디자인 토큰 (`:root` CSS 변수)
| 토큰 | 값 | 용도 |
|---|---|---|
| `--pink` | #FF5C8A | 메인 (CTA·포인트) |
| `--pink-deep` | #E8447A | hover·강조 |
| `--pink-100` | #FFE3EC | 라벨·아이콘 배경 |
| `--pink-50` / `--blush` | #FFF4F8 / #FFEFF5 | 섹션 배경 |
| `--ink` | #2A2A30 | 제목 |
| `--body` | #5E5E68 | 본문 |
| `--muted` | #9A9AA4 | 보조 |
| 제품카드 | #FFEFF4 / #EAF3FB / #FFF1E9 | 파스텔 (자사몰 톤) |
- 폰트: **Noto Sans KR** (Google Fonts, 400/500/700/900)
- 반응형 분기: 960px(태블릿·2단), 640px(모바일·1단+햄버거)
